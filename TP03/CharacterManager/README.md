# Character Manager – TP3 (Java Visual SIH-6406)

## Deskripsi Singkat
Character Manager adalah program Java berbasis Object-Oriented Programming (OOP) yang dibangun untuk mengelola data dan status karakter permainan. Program ini menerapkan konsep dasar class, object, constructor overloading, enum, dan encapsulation pada kelas model karakter. Pada Sprint #1 (TP3), program diperluas dengan menambahkan atribut `mana`, mekanisme validasi setter, serta method `isAlive()` untuk memvalidasi kondisi kelangsungan hidup karakter.
